# Casa Aisha — Company Profile Website

Website resmi untuk proyek hunian **Casa Aisha**, menampilkan konsep hunian modern-dua lantai di lokasi strategis dengan pendekatan desain elegan dan layanan lengkap.

---

## ✨ Highlights

- Menampilkan **1 lokasi, 3 pilihan rumah** dengan desain modern-klasik yang nyaman dan aman.  
- Informasi lengkap tentang spesifikasi rumah (LT/LB, tipe, harga, cicilan) serta fasilitas area.  
- Galeri visual yang memperlihatkan unit dan lingkungan sekitar secara profesional.  
- Call-to-action kontak untuk pemesanan atau konsultasi via WhatsApp.  
- Responsive untuk tampil optimum di desktop maupun mobile.

---

## 🛠 Tech Stack & Setup

> Sesuaikan bagian ini jika kamu menggunakan framework atau tooling tertentu (misal Nuxt, Vite, Tailwind, dll).

Contoh yang mungkin digunakan dalam proyek ini:

- HTML5 + CSS3 (menggunakan Tailwind CSS atau custom CSS)  
- JavaScript (ES6+)    
- Deployment: Hostinger ( hosting shared )
